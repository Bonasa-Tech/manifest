# CU Benchmarks

This directory contains the benchmark harness and its recorded replay corpus.
Run the complete benchmark from the repository root with:

```sh
./scripts/benchmarking/benchmark.sh
```

The harness is an isolated Cargo workspace so its Agave test dependencies do
not affect the program workspace lockfile.

## Cases
Test cases are generated by pulling real data from another CLOB on Solana to get
real world usage patterns. These are periodically pulled from mainnet and saved
as testdata.
```
RPC_URL=<RPC_URL> yarn ts-node scripts/benchmarking/prepare.ts
```

This outputs 3 json. Initial, transactions, and final.
